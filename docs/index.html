3 步 安装

Chrome 非商店扩展需要「开发者模式」加载，一次装好，之后自动用。注意：先解压，再选文件夹 —— zip 本身拖不进去。

1
下载并解压
点上面的按钮下载 zip，解压得到一个 marksync 文件夹。
2
打开扩展页，开「开发者模式」
Chrome 地址栏输入 chrome://extensions 回车，打开右上角的「开发者模式」开关。
3
加载已解压的扩展程序
点「加载已解压的扩展程序」，选中第 1 步解压出的那个文件夹 —— 装好了。
✓
开始用
在浏览器登录你要追的平台网页版，点插件图标 →「同步」。
💡 每次重启 Chrome 可能提示「要停用开发者模式扩展吗」，点「保留」别停用即可。这是 Chrome 对非商店扩展的常规提醒，不是出错。

它能做什么

6 个平台的收藏/点赞，后台悄悄同步，攒成一份待看清单。

🔔 后台自动同步
定时检查各平台新收藏，角标 + 通知提醒，不用你手动翻。
🎯 按平台单独同步
同步按钮带下拉，可只同步某个平台，并显示各自上次同步时间。
📤 一键导出 CSV
整个清单导成表格，Excel 直接打开，来源/标题/链接一应俱全。
🌏 中/英/日 三语
界面跟随浏览器语言自动切换。
装了旧版怎么更新

扩展会自己检查新版本，有新版本时弹出提示。更新有两条路：

A
命令行（最省事，推荐）
装的时候用 git clone，以后一条命令更新。更新完回扩展页点一下刷新图标即可生效。
# 首次安装
git clone https://github.com/wumaohua233/marksync.git ~/marksync

# 以后更新
cd ~/marksync && git pull
B
手动覆盖
下载新 zip，解压后覆盖到原来那个文件夹（系统问「替换」就点替换），然后回 chrome://extensions 点一下 MarkSync 卡片上的刷新图标。
🔒 不用卸载旧的，覆盖就行。扩展 ID 是固定的，所以清单和已读记录不会丢 —— 它们存在浏览器里，不在扩展文件夹里。

数据与隐私

所有数据只存在你自己的浏览器里。没有服务器，没有账号，没有任何上报。

🔍 不用信我，你可以自己核验
代码全在 GitHub 上。全仓库搜索 fetch( ，除了 6 个平台和一个用于探测网络的百度 favicon，没有任何指向第三方的请求；数据存在 chrome.storage.local。有疑惑可以直接在仓库里提 issue。
